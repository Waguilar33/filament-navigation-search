# Rules Index

Filament Navigation Search adds a search field to the top of a panel's sidebar that finds pages in the menu. It is separate from Filament's global search, which finds records.

Read the entry that matches your work before designing, planning or changing it. List the rules your work touches, and raise any conflict before building.

| When your work touches | Read |
|---|---|
| Anything in this plugin: the field, the index, matching, keywords, the collapsed sidebar | [navigation-search-rules.md](navigation-search-rules.md) |

Every rulebook has the same shape: agreed rules with a reason each, a superseded log, facts, and parked items. A rule is never edited silently; the old wording moves to the superseded log.

This folder is export-ignored: it lives in the repository, never in the installed package.
