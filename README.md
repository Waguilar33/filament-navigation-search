# Filament Navigation Search

> **Beta.** The API may change before 1.0.

Search the sidebar navigation of a Filament panel. It is separate from Filament's global search: global search finds records, this finds pages in the menu.

## Requirements

- PHP 8.2+
- Filament 5.10.2+

## Installation

```bash
composer require waguilar33/filament-navigation-search:"^1.0@beta"
```
